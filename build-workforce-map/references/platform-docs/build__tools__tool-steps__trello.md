## 'Trello - Add Checklist' Tool step

> Add a checklist to a card in Trello

The ‘Trello - Add Checklist’ Tool step allows you to add a checklist to one of your Trello cards.

<Note>
  You can learn more about the Trello integration 

  here (page `integrations/popular-integrations/trello`)

  .
</Note>

You can add the ‘Trello - Add Checklist’ Tool step to your Tool by:

1. Creating a new Tool, then searching for the ‘Trello - Add Checklist’ Tool step
2. Click ‘Expand’ to see the full Tool step
3. Select or add your Trello account
4. Select the board your card is on
5. Select the card you want to add a checklist to
6. Name the checklist in the ‘Checklist Name’ field
7. If you wish to copy the items from another checklist, add this checklist’s name to ‘Copy from Checklist’
8. Use the ‘Position’ field to choose whether the checklist is added above or below other checklists on the card
9. Click ‘Run step’ to test out the Tool step!

<Info>
  You will not be able to add checklist items to the checklist item you create in this Tool step unless you copy items from another checklist using the ‘Copy from Checklist’ field. To create new items, you should add another Tool / Tool step using the ‘Trello - Create a Checklist Item’ Tool step.
</Info>

## 'Trello - Create a Checklist Item' Tool step

> Add a checklist item to a checklist in Trello

The ‘Trello - Create a Checklist Item’ Tool step allows you to add a checklist item to one of your Trello checklists.

<Note>
  You can learn more about the Trello integration 

  here (page `integrations/popular-integrations/trello`)

  .
</Note>

### Add the ‘Trello - Create a Checklist Item’ Tool step to your Tool

<Note>
  In order to create a checklist item, you need to create a checklist first. You can do this in Trello or by using the 

  [Add Checklist Tool step](build__tools__tool-steps__trello.md) (page `build/tools/tool-steps/trello/add-checklist`)

  .
</Note>

You can add the ‘Create a Checklist Item’ Tool step to your Tool by:

1. Creating a new Tool, then searching for the ‘Create a Checklist Item’ Tool step
2. Click ‘Expand’ to see the full Tool step
3. Select or add your Trello account
4. Add the board your checklist is on
5. Add the card your checklist is on
6. Select the name of the checklist you want to add a checklist item to
7. Add the name of the checklist item in the ‘Name’ field
8. Use the ‘Position’ dropdown to specify whether the checklist item is added to the top or bottom of the checklist
9. Use the ‘Checked’ checkbox to specify whether the checklist item should be created as checked or not
10. Click ‘Run step’ to test your Tool step!
